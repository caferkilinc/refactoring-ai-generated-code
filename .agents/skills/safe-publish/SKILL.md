description: Publish a Project Genesis feature branch through normal GitHub checks.
---

Verify repository identity, current main, diff scope and local results. Push the
feature branch, open a GitHub PR and verify real checks and required native
reviews for its current revision. Merge through GitHub when eligible and verify
the resulting merge. Follow the
[GitHub workflow](../../../docs/governance/PROJECT_GENESIS_CODEX_NATIVE_PROTOCOL_V3.md).
