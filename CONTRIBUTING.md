# Contribution workflow — Project Genesis

1. Verify the [canonical policy](docs/governance/PROJECT_GENESIS_CODEX_NATIVE_PROTOCOL_V3.md),
   live main, task scope and native GitHub prerequisites.
2. Work from a feature branch. Use an issue-numbered branch for registered product
   tasks so the dependency audit can identify the issue.
3. Open a GitHub PR with the issue link, acceptance evidence and actual test results.
   Link an issue for automatic closure when the change completes its criteria.
4. Merge through GitHub once applicable CI and required reviews pass. Verify the
   merge and the issue state in GitHub.

Preserve the immutable V0, frozen tests, task graph and historical acceptance
records. Use [security guidance](SECURITY.md) and the [team workflow](docs/TEAM_WORKFLOW.md)
for the relevant safeguards.
